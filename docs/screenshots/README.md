# Screenshots

Referenced from the root `README.md`. Drop the PNGs in here with these exact names:

| File | What to capture |
| --- | --- |
| `dashboard.png` | The whole app — header, stat tiles, machine cards, live feed on the right |
| `workspaces.png` | The workspace switcher dropdown, open, showing machine + running counts |
| `new-machine.png` | The "New simulated machine" dialog, *Device & broker* tab |
| `live-feed.png` | The live feed panel with a few JSON messages streaming in |

Shoot them in **light mode** at a normal window width — GitHub renders README images on a
white background, so a dark-mode capture reads as a black slab in the middle of the page.

Keep each one under ~400 KB. `pngquant --quality 65-85` is usually enough.
